Paper

Trajectory

Reconstruct the 3D Gaussians of scenes in a feedforward manner from the given event stream captured by a moving event camera(to collect multiviews).

Input & Output

Input

the asynchronous event stream and encode it into 3D spatial-temporal voxel grid

target view

Output

3D Gaussian representation

Methodology

Monocular Depth Estimation

Input the consecutive event voxel grid EkE_kEk​ and Ek−1E_{k-1}Ek−1​

U-net ϕd\phi_dϕd​ will predict

  • disparity map（视差 ）: The final depth DpredD_{pred}Dpred​ can be converted form the disparity
  • Foreground mask (D): filter out the useless backgrounds

Intensity Reconstruction

Input the event voxel grid, event frame and depth feature volume FdF_dFd​

Also use UNet ϕI\phi_IϕI​ to recover the intensity by multiplying the foreground mask, where FIF_IFI​ is the output feture volume

Gaussian Parameter Regression

And the scale, rotation, opacity are calculated
