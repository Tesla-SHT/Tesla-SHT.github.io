# Top-down Parsing
    left factoring: extract common prefixes 
    ```
    A -> aB | aC
    A -> a(B|C)
    ```
    left recursion: May get into infinite loop since the parser will always choose the leftmost non-terminal
    ```
    A -> Aa | b
    A -> bA'
    A' -> aA' | ε
    ```


# Bottom-Up Parsing (LR Parsing)
    L means tokens are read left to right
    R means the rightmost derivation is reversed
