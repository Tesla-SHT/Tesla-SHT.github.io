# Haotian Shen's Personal Website

This repository contains the source for [my personal website](https://tesla-sht.github.io/). I use it to share my research profile and publications, academic notes, technical write-ups, and occasional personal writing.

The site is built with [Hexo](https://hexo.io/) and the Quiet theme. The `source` branch stores the editable site; the `main` branch stores the generated pages published through GitHub Pages.

## Local development

```bash
npm install
npm run server
```

Run `npm run build` to generate the static site in `public/`.
